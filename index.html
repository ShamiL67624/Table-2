WORKSPACE DOCUMENTATION

Your dashboard, explained.

This workspace combines sample sales reports with QR orders saved locally from customers. The customer menu uses the Item Board catalogue. It is not connected to an external point-of-sale system.

Find the view you need

Use Dashboard for an overview, Orders for the full order table, Item Board for the menu catalogue, and Sales reports for revenue and order mix. Filters remain selected when switching between these pages.

Table capacity and joining

Open Table QR → Tables & seating. T1–T4 start with 4 seats each. Add a table with a name such as T5 and its seat capacity, or leave the name blank to use the next number. Save seats updates an existing table. Select two or more separate tables and choose Join selected tables to combine their seating; Separate restores the individual tables. Joining preserves each QR code. New orders show the joined table group and combined seats; previous orders keep their original details. Joining does not combine receipts or payments.

QR ordering

Open Table QR to print table cards or download their codes. Every table shares the Item Board menu, with its table name attached to each order. Keep the server running and connect customer phones to the same Wi-Fi. Live table orders appear in their own inbox above the sample order reports. Click Confirm order to send “Order confirmed” to that customer’s menu page. Scanning a code opens the menu; only pressing Place order submits an order. Customers pay at the restaurant.

Filter your restaurant activity

Combine date range, location, order type, status, payment method, and customer or order ID search. Every chart, metric, order table, and CSV export uses the same matching orders. Custom dates include both start and end dates. Reset filters restores the last seven days and all locations, types, statuses, and payment methods.

Browse the Item Board

The Item Board sits below the order table and also opens from the sidebar, directly below Orders. It lists sample menu items with their category, availability, and price in INR. Search by name, ID, or description, and combine category and availability filters. Reset item filters shows the full menu. Item filters are separate from order filters; menu items do not affect order metrics or the order CSV.

Understand the numbers

Revenue and average order value count completed orders only. Total orders includes all matching statuses, including cancelled orders. Completion rate is completed orders divided by all matching orders. Amounts use Indian rupees. The revenue chart groups completed sales by calendar day; order mix includes all matching statuses.

Review and export

Sort orders by date or amount and use Previous / Next to page through the results. Export CSV downloads all matching rows in the selected sort order, including rows on other pages. CSV exports include all statuses; use the Completed status filter for completed sales only.
